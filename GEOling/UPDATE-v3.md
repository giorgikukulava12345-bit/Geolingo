# Geolingo v3 — განახლების ინსტრუქცია

## რა დაემატა

- ოთხი მიმართულება: ქართული → ინგლისური; ქართული → რუსული; რუსული → ინგლისური; ინგლისური → რუსული. ზედა ენის მენიუში აირჩიე საწყისი ენა. ქართულ რეჟიმში სასწავლო ენა ცალკე მენიუდან იცვლება; ინგლისურ და რუსულ რეჟიმში შესაბამისი მიმართულება ავტომატურად ირჩევა.
- ძირითადი 240 გაკვეთილის ფრაზები და ახსნები, ასევე 30 ტექსტის თარგმანი და კითხვები ახლა ინგლისურ და რუსულ საწყის ენებსაც ემსახურება. ძველი გაკვეთილების ID-ები და პასუხების სერვერული გადამოწმება შენარჩუნებულია.
- მოსმენა: ორივე ენაში A0, A1, A2, B1, B2. თითო დონეზე რვა მოდული, თითო მოდულში 30 სავარჯიშო. ეს არის 1,200 სავარჯიშო თითო სასწავლო ენაზე და 2,400 ჯამში. სავარჯიშოები თემატური, კონტროლირებადი წინადადებების ვარიაციებია; 2,400 სხვადასხვა გრამატიკული წესი არ არის.
- მოსმენის შემდეგი მოდული იხსნება 80%-იანი შედეგით მინიშნების გარეშე. ყველა დონის პირველი მოდული ღიაა. მინიშნებით პასუხი სწავლისთვის გამოიყენება, მაგრამ დამოუკიდებელ ცოდნად არ ითვლება. მოდული დახურვის შემდეგ დარჩენილი დავალებიდან გრძელდება.
- გრამატიკა: 40 მოდული თითო ენაზე, რვა თითო A0–B2 დონეზე. თითო მოდულში თემის ახსნა, სამი წესი/მოდელი, სამი თარგმნილი მაგალითი, გავრცელებული შეცდომების განმარტება და სამი შესამოწმებელი კითხვა. ჯამში 80 მოდული და 240 კითხვა. ყველა დონე ხელმისაწვდომია.
- 15 ყოველდღიური დიალოგი, 120 რეპლიკით: რესტორანი/კაფე; აეროპორტი/ფრენა; სასტუმრო; მაღაზია; ქალაქი/ტრანსპორტი. თითო კატეგორიაში სამი დიალოგია. თითო რეპლიკა ისმინება, თარგმანი ცალკე იხსნება; ბოლოს როლებით გამეორებაა.
- ნამდვილი გადაკვეთილი კროსვორდები ხუთ თემაზე, ორივე სასწავლო ენისთვის. მინიშნებები საწყის ენაზეა; ასოები სასწავლო ენაზე ივსება. მინიშნებაზე დაჭერა შესაბამის უჯრას ააქტიურებს; მიმართულების შეცვლა ისრებითაც შეიძლება. ასოები ინახება და მოწმდება.
- Geolingo-ს საკუთარი მთის პერსონაჟის ხელის ქნევა, თვალის დახამხამება, სწორი/არასწორი პასუხის რეაქციები, აქტიური გაკვეთილის პულსი და გამარჯვების ანიმაცია. Reduced motion რეჟიმში მოძრაობა გამორთულია.
- მობილურზე გაზრდილი შრიფტი, პასუხები ორ სვეტად, კომპაქტური დავალება და დამაგრებული მოქმედების ღილაკი. ჩვეულებრივ დავალებაში ველი და „შეამოწმე“ თავიდანვე ჩანს. გრძელი ახსნები, ტექსტები და მოდულების სიები განზრახ გადახვევადია. ბრაუზერის დიდი ტექსტის/მასშტაბის პარამეტრები და ეკრანის განსაკუთრებული ზომები განლაგებაზე მოქმედებს.
- X ყველა ფანჯარაში კვლავ მარჯვნივაა.

## სად იპოვი

საიტზე „ივარჯიშე“ → „მოსმენა“, „გრამატიკა“, „ყოველდღიური საუბრები“ ან „კროსვორდები“.

## პროგრესი და ხმა

ძირითადი გაკვეთილების ანგარიშზე შენახვა და XP მუშაობს ძველი წესით. ახალი დამატებითი პრაქტიკის მოდულები ინახება მხოლოდ ამ მოწყობილობის ბრაუზერში, საწყისი ენის, სასწავლო ენისა და ანგარიშის მიხედვით; სხვა მოწყობილობაზე ავტომატურად არ გადავა და ლიდერბორდის XP არ ემატება. ბრაუზერის მონაცემების წაშლა ამ პრაქტიკის ლოკალურ პროგრესსაც წაშლის.

აუდიო კვლავ მოწყობილობის ხელმისაწვდომ ხმებს იყენებს. Azure ანგარიში/Neural ხმა ამ ვერსიას არ დამატებია. მიკროფონის სიტყვების ამოცნობის პრაქტიკა შენარჩუნებულია; რეალურ ხმაზე ხარისხი და ამოცნობის ხელმისაწვდომობა ბრაუზერზეა დამოკიდებული.

A0 აქ დამწყებ საფეხურს ნიშნავს. მასალა A0–B2 თემების სასწავლო საფუძველია; კურსის დასრულება ოფიციალურ CEFR სერტიფიკატს ან B2 ცოდნის გარანტიას არ წარმოადგენს.

## GitHub-ზე ატვირთვა

1. გახსენი Geolingo-v3-Full.zip → Extract All.
2. გახსენი https://github.com/giorgikukulava12345-bit/Geolingo რეპოზიტორიის მთავარი გვერდი.
3. Add file → Upload files.
4. გადაათრიე ამოღებული **GEOling საქაღალდე მთლიანად**, ყველა ახალი ფაილით. ZIP ფაილი თვითონ არ ატვირთო.
5. გადაამოწმე გზა: **GEOling/public/app.js**. არ უნდა იყოს GEOling/GEOling/public/app.js.
6. Commit changes → main. დაელოდე Vercel-ის ახალ deployment-ს და Ready სტატუსს. შემდეგ საიტი Ctrl+Shift+R-ით განაახლე.

აუცილებელია ყველა ახალი JS ფაილის ატვირთვა; მხოლოდ app.js-ის შეცვლა საკმარისი არ არის.

Vercel: Framework Other; Root Directory GEOling; Build Command npm run build; Output Directory dist. თუ package.json რეპოზიტორიის უშუალო ზედა დონეზე დევს, Root Directory ცარიელი უნდა იყოს. პარამეტრის შეცვლის შემდეგ Redeploy გამოიყენე. პლაგინი საჭირო არ არის.

ამ განახლებისთვის **Supabase-ში SQL არ გაუშვა**. არსებული URL, საჯარო გასაღები და ბაზა უცვლელად გამოიყენება.
