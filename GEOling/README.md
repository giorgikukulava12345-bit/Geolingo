# Geolingo v4 — განახლება და გამოყენება

ეს ვერსია სრულად სტატიკურია: სასწავლო მასალა წინასწარ გამზადებულ JavaScript მონაცემთა ობიექტებში ინახება. არ იყენებს OpenAI-ს, Supabase-ს ან სხვა გარე API-ს. ფასიანი გასაღები და მონაცემთა ბაზის დაყენება საჭირო არ არის.

## რა დაემატა

- 320 ძირითადი გაკვეთილი: ინგლისური/რუსული — 120-120, ჩინური/ესპანური — 40-40. დონეები A0, A1, A2, B1, B2. თითო დონის პირველი გაკვეთილი ღიაა, შემდეგისთვის საჭიროა წინა გაკვეთილის 80%-ით გავლა.
- 1,840 ძირითადი ფრაზა და 7,360 ძირითადი სავარჯიშო ოთხი ფორმატით. მინიშნება მხოლოდ მიმდინარე დავალების შესაძლო XP-ს ანახევრებს; პირველად წარმატებით გავლილი გაკვეთილი იძლევა მაქსიმუმ 40 XP-ს. გამეორება იმავე ჯილდოს ხელახლა არ იძლევა.
- 120 გრამატიკული მოდული, წესებით, მაგალითებით, გავრცელებული შეცდომებითა და 1,320 პრაქტიკული კითხვით.
- მოსმენა: თითო ენაზე 40 მოდული, თითო დონეზე 8. ინგლისურ/რუსულ მოდულში 30 დავალებაა (1,200 თითო ენაზე); ჩინურ/ესპანურში — 6 (240 თითო ენაზე).
- 40 ტექსტი, 15 ყოველდღიური დიალოგი ოთხივე ენაზე. თითო ტექსტსა და დიალოგის ენობრივ ვერსიაზე 100 დავალებაა: სულ 100 ბანკი / 10,000 სავარჯიშო. ბანკები იყოფა 10-კითხვიან ბლოკებად. გაგების, სიტყვების გახსენების, მართლწერის, გამოტოვებული სიტყვისა და სიტყვათა რიგის პრაქტიკა ერთსა და იმავე მასალას სხვადასხვა გზით ამუშავებს; ეს არ ნიშნავს 100 დამოუკიდებელ ფაქტს ყოველ მოკლე ტექსტში.
- Word Duel: 10 რაუნდი, თითო პასუხზე 15 წამი, თარგმანის არჩევა და მართლწერა. თამაშის ქულები და XP ცალ-ცალკეა. ჩანართის დამალვისას დრო ჩერდება.
- 8 ინტერაქტიული ამბავი, 80 სცენა, 24 შესაძლო დასასრული. ორიგინალური ანიმაციური მელა, კომეტა და მთის მეგზური. კროსვორდები ამოღებულია.
- შეცდომების საგანძური: ძირითადი გაკვეთილებიდან, თამაშებიდან, გრამატიკიდან, მოსმენიდან და კითხვის ბანკებიდან. სწორი გამეორება შეცდომას აღდგენილად მონიშნავს.
- ორშაბათი–კვირა კალენდარი, რეალური აქტივობის სერია, სამი დღიური მისია, ერთჯერადი ჯილდოები და გვერდზე შეხსენება.

## GitHub-ზე ატვირთვა

1. საიტზე, ძველ ბრაუზერში, თუ პროფილის ჩამოტვირთვის ღილაკი გაქვს, ჯერ შეინახე პროგრესის ფაილი. ბრაუზერის მონაცემები არ გაასუფთაო.
2. გახსენი ZIP და ამოიღე **GEOling** საქაღალდე. ZIP თვითონ არ ატვირთო კოდის ნაცვლად.
3. გახსენი შენი GitHub რეპოზიტორია **giorgikukulava12345-bit/Geolingo**.
4. რეპოზიტორიის მთავარ გვერდზე: **Add file → Upload files**. ჩააგდე ამოღებული **GEOling** საქაღალდე, რომ ფაილები იმავე `GEOling/public/...` მისამართებზე განახლდეს. არ შექმნა `GEOling/GEOling` ჩადგმული საქაღალდე.
5. ჩაწერე commit: `Update Geolingo v4 offline` და აირჩიე **Commit changes** მთავარ `main` შტოზე.
6. თუ ძველ რეპოზიტორიაში `public/crosswords.js` ან `public/config.js` დარჩება, ახალი build მათ გამოქვეყნებულ ფაილებში აღარ გადაიტანს. შეგიძლია GitHub-იდანაც წაშალო. ძველი Supabase SQL და CONNECT სკრიპტები ამ ვერსიას არ სჭირდება; ბაზა არ წაშალო.

## Vercel

ახალი პლაგინი და ახალი პროექტის შექმნა არ გჭირდება. არსებული პროექტი, თუ GitHub-ს უკავშირდება, commit-ის შემდეგ ავტომატურად განახლდება.

**Settings → Build and Deployment:**

| პარამეტრი | მნიშვნელობა |
| --- | --- |
| Framework Preset | Other |
| Root Directory | GEOling |
| Build Command | npm run build |
| Output Directory | dist |
| Install Command | დატოვე ავტომატური |
| Node.js | 24.x, ან მხარდაჭერილი 20+ |

გადადი **Deployments**, გახსენი ბოლო ჩანაწერი და დაელოდე **Ready** სტატუსს. შემდეგ **Visit**. თუ ავტომატურად არ დაიწყო, ბოლო deployment-ის მენიუში აირჩიე **Redeploy**. თუ ეკრანი ძველია, გააკეთე Ctrl+Shift+R. ამ არქივის მომზადება თავისთავად live საიტს არ ცვლის.

საიტს აღარ სჭირდება Supabase environment variables. ძველ ანგარიშსა და ბაზას ეს განახლება არ ცვლის. Vercel-ის უფასო გეგმა ექვემდებარება თავად ჰოსტინგის შეზღუდვებს; აპს გარე API-ის ხარჯი და ლიმიტები არ აქვს.

## პროფილები, ქულები და რეიტინგი

**პროფილები** ღილაკიდან შექმენი სახელი. პაროლი/ელფოსტა არ არის: ეს ამ ბრაუზერის ადგილობრივი პროფილია, არა ონლაინ ანგარიში. ქულები, შეცდომები, მოდულები, მისიები და სერიები ინახება მოწყობილობაზე.

ლიდერბორდი ადარებს **ამავე ბრაუზერში შექმნილ ნამდვილ პროფილებს**. კვირა ორშაბათიდან იწყება. გამოგონილი მონაწილეები არ არის. სხვადასხვა მოწყობილობის საერთო ონლაინ რეიტინგსა და ავტორიზაციას სერვისი სჭირდება; მოთხოვნის შესაბამისად ამ ვერსიაში ასეთი API არ გამოიყენება.

პროგრესის გადასატანად: **პროფილები → პროფილის ჩამოტვირთვა**. სხვა მოწყობილობაზე: **ფაილიდან შემოტანა**. იქ ახალი ადგილობრივი პროფილი შეიქმნება. პირადი რეჟიმის დახურვამ ან ბრაუზერის მონაცემების წაშლამ შეიძლება პროგრესი წაშალოს, ამიტომ პერიოდულად ჩამოტვირთე ასლი. ძველი ვერსიის ამავე ბრაუზერში დაკეშილი პროგრესი გადაიტანება; მხოლოდ ღრუბელში დარჩენილი ჩანაწერების ჩამოტვირთვა გარე API-ის გარეშე არ ხდება.

## ხმა და მიკროფონი

მოსასმენი ტექსტები ადგილობრივია. გახმოვანებისთვის გამოიყენება მხოლოდ მოწყობილობაზე დაყენებული **ადგილობრივი სისტემური ხმა**. თუ კონკრეტული ენის ოფლაინ ხმა არ არის, აპი ამას გაცნობებს; ტექსტის ნახვა/პრაქტიკა მაინც ხელმისაწვდომია. ხმის ხარისხი მოწყობილობაზეა დამოკიდებული; პროფესიონალური ჩაწერილი აუდიო ამ არქივში არ არის.

Speaking-ში დააჭირე მიკროფონს, დაუშვი მიკროფონი და გაიმეორე. მეორედ დაჭერა აჩერებს ჩაწერას (ავტომატური ზღვარი 20 წამია). მოუსმინე შენს ჩანაწერს და ნიმუშს, შემდეგ მონიშნე, რომ შეადარე. ჩანაწერი სერვერზე არ იგზავნება, ფანჯრის დახურვისას იწმინდება. ავტომატური გამოთქმის სიზუსტის შეფასება არ არის — აპი ხელოვნურ პროცენტს არ გაჩვენებს. მიკროფონს სჭირდება HTTPS ან localhost. მოტივაცია: **პატარა ნაბიჯი დიდი მიზნისკენ**.

## ინტერნეტის გარეშე და შეხსენება

პირველი გახსნისას საჭიროა საიტის ფაილების ჩამოტვირთვა (დაახლოებით 11 MB). Service Worker შემდეგ მასალას ინახავს ოფლაინ გამოყენებისთვის. პირველი ჩატვირთვის დასრულების შემდეგ გვერდი განაახლე. ახალი ვერსიის გამოქვეყნების შემდეგ კიდევ განახლება შეიძლება დაგჭირდეს. ბრაუზერს შეუძლია ქეშის გაწმენდა, ამიტომ ეს ფაილების სარეზერვო ასლი არ არის.

მისიები ყოველდღე ახლდება. შეხსენება არჩეულ ადგილობრივ დროს ჩანს **მხოლოდ მაშინ, როცა გვერდი გახსნილია**. დახურულ ბრაუზერში push-შეტყობინება ამ სტატიკურ ვერსიას არ აქვს.

## კომპიუტერზე გაშვება

დაყენებული უნდა იყოს Node.js 20 ან ახალი. გახსენი **GEOling/START.cmd**, ან ტერმინალში ამ საქაღალდიდან:

```text
npm run dev
```

შემდეგ გახსენი `http://localhost:3000`. ფანჯარა ღია დატოვე. HTML ფაილის ორჯერ დაჭერით გახსნა ES მოდულების გამო არ მუშაობს. თუ პორტი დაკავებულია, PowerShell-ში: `$env:PORT='3074'; npm run dev`, შემდეგ გახსენი `http://localhost:3074`.

საკონტროლო ბრძანებები: `npm test` და `npm run build`. `qa/`-ში დამატებითი UI ტესტებია; მხოლოდ მათთვის გაუშვი `npm install` იმ საქაღალდეში (jsdom, Node 24). აპის მუშაობას jsdom და npm-დამოკიდებულებები არ სჭირდება.

## მასალის რედაქტირება

ყველაფერი `public/`-შია: `new-courses-v4.js` (ჩინური/ესპანური), `curriculum.js` და გაფართოებები (ინგლისური/რუსული), `grammar-v4.js` და ახალი ენების გრამატიკა, `practice-bank*-v4.js` (100-კითხვიანი ბანკები), `interactive-stories-v4.js` (არჩევითი ამბები), `content-v4.js` (მასალების გაერთიანება), `local-state.js` (ქულები/პროფილები), `style.css` (დიზაინი).
