# GEOling v2 — განახლების ინსტრუქცია

მიმდინარე GEOling პროექტში Supabase-ის v2 განახლება უკვე წარმატებით შესრულებულია. ქვემოთ SQL-ის ინსტრუქცია სხვა/ახალი გარემოსთვის და ხელახალი გადამოწმებისთვისაც არის მოცემული; არსებულ პროექტში თავიდან გაშვება საჭირო არ არის.

## რა შეიცვალა

- თითოეული სასწავლო დონის პირველი გაკვეთილი თავიდანვე ღიაა; დონის შიგნით შემდეგი გაკვეთილები 80%-ით იხსნება.
- ყველა ფანჯარა იხურება გარეთ განთავსებული × ღილაკით, ფანჯრის გარეთ დაწკაპუნებით ან Esc-ით. საუბრის ფანჯრის დახურვა მიკროფონის ჩანაწერს აჩერებს.
- გაკვეთილის დასაწყისში არის სიტყვებისა და ფრაზების გაცნობა: ტექსტი, ქართული თარგმანი, მიახლოებითი გამოთქმა და მოსმენა.
- მინიშნება პასუხს აჩვენებს და მხოლოდ იმ დავალების ქულას ანახევრებს. სწორი პასუხების 80%-იანი ზღვარი უცვლელია. მაქსიმალური პირველი გავლის XP არის 40; ყველა დავალებაზე მინიშნებით — 20. ჯამი მრგვალდება მთელ ქულამდე. განმეორებით გავლაზე XP აღარ ირიცხება.
- 240 გაკვეთილი (120 თითო ენაზე), 1360 სიტყვა/ფრაზის ჩანაწერი, 5440 ძირითადი სავარჯიშო.
- დამატებით 30 ორიგინალური ტექსტი/დიალოგი, სრული ქართული თარგმანი, სინთეზირებული მოსმენა და 90 გაგების კითხვა. ტექსტების პრაქტიკა თავისუფალია და XP არ გასცემს.

## მნიშვნელოვანი: ჯერ ბაზა, შემდეგ საიტი

ამ ვერსიის ქულები და ახალი გაკვეთილები საჭიროებს Supabase-ის განახლებას. მხოლოდ config.js-ის შეცვლა საკმარისი აღარ არის.

1. Supabase-ში გახსენი არსებული GEOling პროექტი (`blbodppmgmhqfkqbhuch`).
2. გახსენი **SQL Editor → New query**.
3. ამ ვერსიის `supabase/upgrade-v2.sql` ფაილის მთელი შიგთავსი ჩასვი და გაუშვი **Run**.
4. მოიცადე წარმატებული დასრულება. ეს სკრიპტი ინახავს არსებულ ანგარიშებს, გავლილ ძველ გაკვეთილებსა და ქულებს. განახლებას იმავე ვერსიით ხელახლაც გაუშვებ.
5. GitHub-ის repository-ში გახსენი **GEOling** საქაღალდე, ატვირთე განახლებული პროექტის შიგთავსი იგივე განლაგებით და შეინახე commit. განსაკუთრებით მნიშვნელოვანია public/, scripts/ და supabase/ ფაილების სრული ჩანაცვლება/დამატება.
6. Vercel-ის Root Directory შენს repository-ში არის **GEOling**. Build Command: `npm run build`; Output Directory: `dist`.
7. დაელოდე ახალ **Ready** გამოქვეყნებას და გახსენი https://giolingo.vercel.app/ .

არსებულ პროექტში **schema.sql თავიდან არ გაუშვა**. სრულიად ახალი ბაზის შესაქმნელად ჯერ schema.sql გამოიყენება და შემდეგ upgrade-v2.sql.

## შემოწმება

1. შესვლის გარეშე გადადი B1-ზე — პირველი გაკვეთილი გახსნილი უნდა იყოს, მეორე ჩაკეტილი.
2. გახსენი გაკვეთილი და წაიკითხე გრამატიკა/სიტყვები. დახურე გარეთ დაწკაპუნებით; შემდეგ თავიდან გახსენი.
3. დავალებაში გამოიყენე მინიშნება — პასუხი უნდა გამოჩნდეს, შესაძლო ქულა კი განახევრდეს. ხელახლა დაჭერა დამატებით ქულას აღარ აკლებს.
4. ანგარიშიანი მომხმარებლით გაიარე გაკვეთილი. გადაამოწმე ქულები და გვერდი განაახლე.
5. Practice-ში გახსენი „ტექსტები და დიალოგები“, მოუსმინე, ნახე თარგმანი და უპასუხე სამ კითხვას.

თუ შენახვისას ჩანს, რომ ბაზის განახლებაა საჭირო, გადაამოწმე, რომ upgrade-v2.sql ზუსტად იმ Supabase პროექტში გაუშვი, რომელიც public/config.js-შია მითითებული.

## კურსის მოცულობის განმარტება

5440 სავარჯიშო არის 1360 ჩანაწერის ოთხი ტიპის პრაქტიკა: მნიშვნელობის არჩევა, მოსმენის ჩაწერა, თარგმნა და სიტყვების დალაგება. დამატებით 90 კითხვა ტექსტების გაგებას ამოწმებს. ეს მნიშვნელოვნად გაზრდილი ბაზაა, თუმცა Duolingo-ს სრული მოცულობის, დამოუკიდებელი სასერტიფიკაციო B2 კურსის ან მასწავლებლის შეფასების ტოლფასად არ არის წარმოდგენილი. ქართული გამოთქმის მინიშნებები მიახლოებითია; აუდიო ბრაუზერის ხმას იყენებს.
